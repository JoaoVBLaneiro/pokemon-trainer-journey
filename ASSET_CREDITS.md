# Trainer Journey — Asset Credits

Trainer Journey is an unofficial Pokémon fan project. This file tracks third-party environment assets used by the Habitat feature.

## Used in the Habitat

### Kenney — RPG / Roguelike assets

- **Artist:** Kenney
- **Primary source:** https://kenney.nl/assets/roguelike-rpg-pack
- **License:** Creative Commons Zero 1.0 Universal (CC0)
- **Usage:** island ground texture, pond texture, trees and fence scenery in the Habitat.
- **Attribution:** not required by the license, but gratefully included here.

The small vendor script included with this project retrieves the same CC0 files from an extracted public mirror at:
https://github.com/ETdoFresh/kenney.nl
